# THE-GLOBAL-KITCHEN-RECIPE-API

The GLOBAL KITCHEN is a backend RESTful API designed to manage a digital cookbook.

## The Global Kitchen API

## Tech Stack

- Runtime: Node.js
- Framework: Express.js
- Database: MongoDB
- Configuration: dotenv

## Features

- Create recipes
- Get all recipes
- Filter recipes by category
- Update recipes
- Delete recipes

## Installation & Setup

1. Clone repository

```bash
git clone YOUR_REPOSITORY_URL
```

2.Install dependencies

```bash
npm install
```

3.Create .env file

```env
PORT=5000
MONGODB_URI=YOUR_CONNECTION_STRING
```

4.Run server

```bash
npm run dev
```
